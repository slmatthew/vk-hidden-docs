# utils.guessUserSex
Получить пол пользователя, основываясь на имени и фамилии

## Параметры

| Параметр   | Тип    | Описание   |
|------------|--------|------------|
| first_name | string | Имя        |
| last_name  | string | Фамилия    |
| full_name  | string | Полное имя |

## Доступ
Этот метод можно вызвать без передачи `access_token`. Достаточно передать `client_id` и `client_secret` от официального приложения. Я использовал данные от VK для Android:
* `client_id = 2274003`
* `client_secret = hHbZxrka2uZ6jB1inYsH`

## Пример ответа
Возможно три значения поля `sex`:
* `male` - мужской
* `female` - женский
* `unknown` - не удалось определить пол
* `undefined` - невозможно определить пол так как нет ни имени, ни фамилии. `full_name` не решает эту проблему

```json
{
  "response": {
    "sex": "undefined"
  }
}
```
