## utils.guessUserSex

Возвращает пол пользователя, основываясь на его имени и фамилии.

### Доступ

Этот метод работает без передачи `access_token`. Вы должны передать `client_id` и `client_secret` от одного из официальных приложений ВКонтакте.

Можно использовать данные от VK для Android:
* `client_id = 2274003`
* `client_secret = hHbZxrka2uZ6jB1inYsH`

### Параметры

| Параметр   | Тип    | Описание   |
|------------|--------|------------|
| first_name | string | Имя        |
| last_name  | string | Фамилия    |
| full_name  | string | Полное имя |

Ни один из этих параметров не является обязательным, но для работы метода необходимо передать либо `first_name`, либо `last_name`.

### Тип возвращаемого значения

* `male` - мужской
* `female` - женский
* `unknown` - не удалось определить пол
* `undefined` - нет ни имени, ни фамилии, или передано мужское имя и женская фамилия

```ts
interface UtilsGuessUserSex {
  sex: 'male' | 'female' | 'unknown' | 'undefined'
}
```
