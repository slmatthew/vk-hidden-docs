# settings.getReserveCodes
Получить список резервных кодов 2FA

## Параметры

| Параметр | Тип    | Описание                                                       |
|----------|--------|----------------------------------------------------------------|
| hash     | string | `codes_hash` из [settings.getSecurityInfo](getSecurityInfo.md) |
