# bugtracker.saveUserDevice
Сохранить настройки устройства

## Параметры

| Параметр         | Тип    | Описание      |
|------------------|--------|---------------|
| user_device_id   | int    | ID устройства |
| hash             | string | `edit_hash`   |
| platform_version | int    | ID версии ОС  |
