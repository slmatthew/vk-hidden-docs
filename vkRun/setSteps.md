# vkRun.setSteps
Шагомер

## Параметры
| Параметр | Тип    | Описание                        |
|----------|--------|---------------------------------|
| steps    | int    | Количество шагов                |
| distance | int    | Дистанция ходьбы (в метрах)     |
| date     | string | Дата в формате `год-месяц-день` |

## Пример ответа
```json
{
  "response": {
    "steps": 2,
    "distance": 7
  }
}
```
