# bugtracker.bookmark
Добавить отчёт в закладки или удалить его оттуда.

## Параметры

| Параметр     | Тип    | Описание                           |
|--------------|--------|------------------------------------|
| bugreport_id | int    | ID репорта                         |
| hash         | string | `bookmark_hash` из объекта репорта |

## Пример ответа
```json
{
  "response": {
    "is_bookmarked": true
  }
}
```
